# Виджет банковских операций клиента

## Описание:

Виджет банковских операций клиента - это веб-приложение на Python для управления банковскими операциями.

## Цель проекта:

Создать приложение для работы с банковскими операциями

## Установка:

Клонируйте репозиторий:

```
git clone https://github.com/username/project-x.git
```

Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Пример работы с функциями:

1. Функция `get_mask_card_number` принимает на вход номер карты и возвращает ее маску. Номер карты замаскирован и
   отображается в формате
   XXXX XX** **** XXXX.
2. Функция `get_mask_account` принимает на вход номер счета и возвращает его маску. Номер счета замаскирован и
   отображается в формате **XXXX.
3. Функция `mask_account_card` принимает строку, содержащую тип и номер карты или счета, и возвращает строку с
   замаскированным номером.
4. Функция `get_date` принимает строку с датой в формате "YYYY-MM-DDTHH:MM:SS.ssssss" и возвращает строку с датой в
   формате "ДД.ММ.ГГГГ".
5. Функция `filter_by_state` фильтрует список словарей по значению ключа 'state'.
6. Функция `sort_by_date` сортирует список словарей по значению ключа 'date'.
7. Функция `filter_by_currency` возвращает итератор, который поочередно выдает транзакции, где валюта операции 
   соответствует заданной (например, USD).
8. Функция `transaction_descriptions` принимает список словарей с транзакциями и возвращает описание каждой операции
   по очереди.
9. Функция `card_number_generator` выдает номера банковских карт в формате XXXX XXXX XXXX XXXX, где X — цифра номера карты, 
   генератор может сгенерировать номера карт в заданном диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999,
   генератор должен принимать начальное и конечное значения для генерации диапазона номеров.
10. Декоратор `log` логирует начало и конец выполнения функции, а также результаты или ошибки. Логи могут быть записаны 
    в файл или выведены в консоль.
11. Функция `get_data` загружает данные из JSON-файла и возвращает их в виде списка.
12. Функция `read_csv_transactions` считывает финансовые операции из CSV-файла.
13. Функция `read_excel_transactions` считывает финансовые операции из Excel-файла.
14. Функция `get_amount_rub` конвертирует сумму транзакции в рубли.
15. Функция `filter_operations` принимает список словарей с данными о банковских операциях и строку поиска,
   а возвращает список словарей, у которых в описании есть данная строка. 
16. Функция `count_by_categories`  принимает список словарей с данными о банковских операциях 
   и список категорий операций, а возвращает словарь, в котором ключи — это названия категорий, а значения 
   — это количество операций в каждой категории.

## Тестирование

Для тестирования функционала используется фреймворк pytest. Тесты находятся в директории tests и покрывают основные
функции проекта.

Для запуска тестов выполните команду:

```
pytest
```

## Описание тестов:

1. **Тестирование функции** `get_mask_card_number`:
   Проверка правильности маскирования номера карты.
   Проверка работы функции на различных входных форматах номеров карт, включая граничные случаи и нестандартные длины
   номеров.
   Проверка, что функция корректно обрабатывает входные строки, где отсутствует номер карты.
2. **Тестирование функции** `get_mask_account`:
   Проверка правильности маскирования номера счета.
   Проверка работы функции на различных входных форматах номеров счетов, включая граничные случаи и нестандартные длины
   номеров.
3. **Тестирование функции** `mask_account_card`:
   Проверка правильности маскирования номера карты или счета в строке.
   Проверка работы функции на различных входных форматах строк, включая граничные случаи и нестандартные длины номеров.
4. **Тестирование функции** `get_date`:
   Проверка правильности преобразования формата даты.
   Проверка работы функции на различных входных форматах строк даты, включая граничные случаи.
5. **Тестирование функции** `filter_by_state`:
   Проверка правильности фильтрации списка словарей по значению ключа 'state'.
6. **Тестирование функции** `sort_by_date`:
   Проверка правильности сортировки списка словарей по значению ключа 'date'.
7. **Тестирование функции** `filter_by_currency`: Проверяет, что функция filter_by_currency корректно фильтрует 
   транзакции по заданной валюте.
8. **Тестирование функции** `transaction_descriptions`: Проверяет, что генератор transaction_descriptions возвращает 
   правильные описания транзакций.
9. **Тестирование функции** `card_number_generator`: Проверяет, что генератор card_number_generator возвращает 
   правильные номера карт.
10. **Тестирование декоратора** `log`: Проверяет, что декоратор корректно логирует успешное выполнение функции; 
   что декоратор корректно логирует ошибки, включая тип ошибки и входные параметры; что логи записываются в файл, 
   если указан параметр `filename`; что логи выводятся в консоль, если параметр `filename` не указан.
